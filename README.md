# 이 대사, 어느 무대? (가칭)

대사 한 줄만 보고 어느 작품인지 맞히는 퀴즈. 한 판을 5·10·20·40문제 중에서 고른다(기본 10).
정지 파일만 올라가는 정적 페이지다.

- 도메인(가칭): <https://stage.acttub.com> — 붙어 있고, 링크 허브(`link.acttub.com`)의 "가볍게 해보기"에서도 들어온다.
- 역할: acttub 코어(질문 기반 연기 연습)로 사람을 태우기 위한 유입용 서브프로젝트.
  성공 지표는 **도달·공유**지 코어의 완주율이 아니다.

## 무엇을 하는 물건이고, 무엇이 아닌가

맞히는 건 **작품 이름**이다. 연기를 평가하지 않는다. 점수·등급·랭킹이라는 말이
연기에 붙는 순간 이 서비스는 옛 평가 서비스로 읽히므로, 결과의 이름표는 끝까지
"극을 얼마나 봤나"에 대한 것으로만 둔다.

정답을 공개할 때마다 **그 대사를 연기한다면 먼저 답해야 할 질문**이 한 줄 붙는다.
그 질문에는 답을 달지 않는다 — 답을 정하는 자리가 배우의 몫이고, 그게 코어로 잇는 다리다.

## 파일

| 파일 | 무엇 |
|---|---|
| `index.html` | 화면 골격만. 문장은 없다 |
| `copy.js` | **사용자에게 보이는 문장의 정본.** 화면 코드는 여기 있는 문장만 주입한다 |
| `data.js` | 문항 58개(대사·정답·오답 보기·장면 한 줄·연기 질문) + 한 판 만들기 |
| `app.js` | 화면 전환과 채점 |
| `src/input.css` | Tailwind v4 입력. `styles.css`를 굽는 원본 |
| `src/brand/` | 볼트 `brand/`에서 온 생성물. **직접 고치지 않는다** |
| `styles.css` · `fonts/` | 빌드 산출물. 커밋해서 그대로 배포한다 |
| `og.jpg` | 카카오톡·SNS 공유 카드(1200×630). 배포된다 |
| `design/` | 화면 시안(`.pen`), 공유 카드 원본과 렌더 스크립트. **배포되지 않는다**(`.vercelignore`) |

## 화면을 고칠 때

시안은 `design/화면-2026-07-28.pen`(pen.dev)이고 시작·문제·답 고른 뒤·결과 네 화면이 들어 있다.
**캔버스는 시안까지고 구현 기준은 `index.html`이다** — pen의 기계 export는 390px 고정에
토큰이 풀린 코드라 여기에 옮기지 않는다. 캔버스에는 Pretendard가 없어 표시용으로 Noto Sans KR을
쓰므로 글자 폭이 실제와 다르다. 줄바꿈은 항상 실제 화면에서 확인한다.

## 저작권

실린 작품은 전부 **보호기간이 끝난** 고전 희곡이다(셰익스피어 · 그리스 비극 · 체호프 ·
입센 · 몰리에르 · 괴테 · 고골 · 뷔히너 · 스트린드베리 · 와일드 · 벤 존슨 · 웹스터 ·
코르네유 · 라신 · 보마르셰 · 실러 · 클라이스트 · 칼데론).

문항을 늘릴 때 **1930년 이전 사망 작가**로 잡아 두었다. 실제로는 버나드 쇼(1950)·
오닐(1953)·피란델로·로르카(1936)도 한국 저작권법상 이미 만료됐을 가능성이 크지만
(1962년 이전 사망분은 사후 50년으로 소멸), 그건 법률 확인을 받고 열 일이다.

⚠️ **한국어 대사는 시중 번역본을 옮긴 게 아니라 여기서 새로 옮긴 문장이다.**
원작이 자유로워도 번역문에는 번역자의 저작권이 따로 붙기 때문이다. 문항을 추가할 때
번역본에서 문장을 가져오지 않는다.

⚠️ 현대극(고도를 기다리며 · 세일즈맨의 죽음 · 욕망이라는 이름의 전차 등)은 보호기간이
남아 있어 빼 두었다. 인지도가 높은 작품들이라 재미로는 아깝지만, 넣으려면 인용 범위
판단이 먼저다.

## 만들기

```bash
npm install
npm run css          # src/input.css → styles.css
npm run serve        # 로컬 확인

# 문구나 대사를 고쳤으면 폰트를 다시 굽는다 (안 굽면 새 글자가 시스템 폰트로 렌더된다)
uv run --with "fonttools[woff]" python build-fonts.py
```

`src/brand/`는 내부 디자인 정본에서 생성돼 들어온 파일이다. 값이 바뀌면 그쪽 동기화
스크립트로 다시 받아온다 — **손으로 베끼면 갈라진다.**

## 배포 전 게이트

기기 매트릭스 하네스(20개 프리셋)를 돌린다.

⚠️ 이 하네스는 **첫 화면만** 본다. 문제·결과 화면은 `hidden`으로 시작하므로 거기 걸리지 않는다.
화면을 고쳤으면 한 판을 끝까지 눌러보고 결과 화면까지 직접 확인한다.

⚠️ 하네스가 검증하는 건 레이아웃·CSS 계산이다. 노치·키보드 가림·웹폰트 실패·색감은
**실제 아이폰 사파리와 인스타 인앱에서 한 번** 봐야 한다. 게시 전 수동 확인은 대체되지 않는다.

`git push origin main`이 곧 Vercel 배포다. 푸시는 소유자 승인 후에 한다.
